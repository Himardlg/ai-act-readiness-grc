# Security Policy

## Project status

This is an exploratory prototype and does not provide enterprise-grade security guarantees.

## Reporting a vulnerability

Please report security issues privately to the repository maintainer before publicly sharing technical details. Do not include credentials, personal data or confidential business information in reports.

## Data handling

The standalone version stores records in browser local storage. This is not an encrypted database, secure backup or substitute for access-controlled production storage.

Do not enter sensitive, confidential or personal information.

## Before production use

A production deployment would require security review covering authentication, authorization, storage, data protection, audit logging, backups and incident response.
