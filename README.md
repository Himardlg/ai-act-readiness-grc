# AI Act Readiness GRC MVP

**A practical prototype for AI Governance, Risk Management and Compliance readiness.**

AI Act Readiness GRC MVP is an exploratory prototype designed to help structure initial readiness activities related to the European Union Artificial Intelligence Act (EU AI Act).

## Features in this prototype

- Project creation, editing and deletion.
- Initial self-assessment checklist associated with projects.
- Risk register with level, status, owner and target date.
- Dashboard summaries.
- Spanish and English interface.
- JSON data export and import.
- Standalone HTML interface with no server required for basic local use.

## Getting started

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Create a project and explore the assessment and risk register.
4. Export JSON backups regularly.

Browser behavior for local files (`file://`) can vary. Data is stored in browser local storage and may not be shared across browsers or devices. Do not enter sensitive, confidential or personal information.

## Regulatory context

The project is inspired by Regulation (EU) 2024/1689 (the EU Artificial Intelligence Act).

- [Official legal text — EUR-Lex](https://eur-lex.europa.eu/eli/reg/2024/1689/oj)
- [European Commission — regulatory framework for AI](https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai)

## Limitations and disclaimer

This is an exploratory software prototype. It is not an official EU assessment mechanism, certification tool, legal opinion or guarantee of compliance. It does not automatically determine an AI system's legal classification or establish that an organization meets all applicable obligations.

Organizations should validate assessments against applicable legislation, current official guidance and their circumstances, seeking qualified legal or compliance advice where appropriate. Do not use this prototype as the sole basis for legal, regulatory or high-impact decisions.

## Roadmap ideas

Potential future work includes AI system inventory, detailed legal mapping, evidence traceability, audit trails, workflow approvals, access controls, secure centralized storage and reporting. These are ideas, not claims that the features are already implemented.
